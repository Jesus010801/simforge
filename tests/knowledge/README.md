# SSKI Tests

Planned categories:

- `architecture/` — dependency and invariant tests
- `domain/` — pure model invariants
- `identity/` — identity/alias/mapping behavior
- `federation/` — transport/cache contracts with mocks/fixtures
- `importers/` — fixture-based scientific parsing
- `policies/` — deterministic decision semantics
- `compiler/` — bundle compilation/integrity
- `runtime/` — no-network/fail-fast/read-only bundle behavior

Source importer tests should not require Internet access.
